# docs

- `decisions/`: one short file per decision that changes the plan, named `NNNN-title.md` (context, decision, consequences). Create it with the first decision.
- `archive/`: earlier plans kept for history. `plan-v7.html` is the 24-week stage plan; `plan-v8.html` is the 13-section draft that led to the current board. `site-v6.html` is the project site before the v9 roadmap. Open them in any browser.
